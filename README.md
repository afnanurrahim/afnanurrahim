## 📊 Taxi ETA Forecasting

**Description**:  
Developed a robust NYC taxi ETA prediction system using XGBoost, PySpark, and FastAPI to predict the Estimated Time of Arrival (ETA) for taxis based on historical trip data.

**Technologies Used**: XGBoost, PySpark, FastAPI, Tableau, Streamlit

**Highlights**:  
- Achieved a 45% reduction in Mean Absolute Error (MAE) over baseline models.
- Built an interactive dashboard to analyze model predictions and errors.
- Processed a large dataset of 16 million trips for feature engineering.

**Link to Repository**: [GitHub - Taxi ETA Forecasting](https://github.com/afnanurrahim/New-york-taxi-ETA)

## 🐍 **NLP Preprocessing Library**

**Description**:  
Developed a Python package, *nlp_lib*, designed to streamline common Natural Language Processing (NLP) preprocessing tasks. This package offers a variety of functionalities to clean and transform text data, making it easier for users to perform NLP tasks efficiently.

**Features**:  
- **Emoji Removal and Replacement**: Quickly remove or replace emojis within text for better text clarity.
- **HTML Tag Removal**: Clean HTML tags from raw text, preserving the content and improving text quality for further analysis.
- **Special Character Removal**: Cleanse text by removing unwanted special characters for cleaner data.
- **Abbreviation Expansion**: Expand common abbreviations into their full forms (e.g., "lmao" to "laugh my ass off").
- **Contraction Expansion**: Convert contractions into their expanded forms (e.g., "aren’t" to "are not").
- **Word Segmentation**: Efficiently segment unstructured words (e.g., "Thisisasampletext" to ["this", "is", "a", "sample", "text"]).

**Technologies Used**: Python

**Link to Repository**: [GitHub - nlp_python_package](https://github.com/afnanurrahim/nlp_python_package)
